# فيديو تعليمي: حساب العدد الذري والعدد الكتلي ومكونات الذرة

فيديو موشن جرافيك لطلاب الصف الأول المتوسط، بُني بـ Remotion و three.js (رسوم ثلاثية الأبعاد حقيقية).

- **الملف النهائي:** `out/atomic-number-lesson.mp4`، بترميز H.264 للصورة وAAC للصوت، بدقة 1920×1080 (16:9)، و30 إطاراً في الثانية، ومدته 54.8 ثانية.
- **التعليق الصوتي:** صوت عربي ذكوري بالفصحى من Piper (`ar_JO-kareem-medium`)، يُولَّد محلياً من نص مشكول بالكامل.
- **الموسيقى:** خلفية هادئة مولَّدة برمجياً وخالية من الحقوق. مستواها منخفض جداً، وتنخفض أكثر أثناء الكلام.

## المشاهد

| المشهد | المدة | المحتوى |
|---|---|---|
| 1. المقدمة | 6.4 ث | عنوان الدرس وذرة كربون ثلاثية الأبعاد تدور |
| 2. العدد الذري | 11.1 ث | تقترب الكاميرا من النواة، وتظهر البروتونات الستة مرقّمة من 1 إلى 6 وتُعتَّم النيوترونات |
| 3. العدد الكتلي | 13.2 ث | تطير رموز البروتونات والنيوترونات إلى المعادلة 6 + 6 = 12 |
| 4. النيوترونات والإلكترونات | 14.3 ث | المعادلة 12 − 6 = 6، ثم تظهر الإلكترونات: 2 في المستوى الأول و4 في الثاني (نموذج بور) |
| 5. الملخص | 9.8 ث | بطاقة نتائج الكربون-12 وتذكير بالقاعدتين |

## التزامن مع الصوت

تُستخرج من محرك الصوت لحظة نطق كل كلمة، وتُحفظ في `src/voice-timing.json`. تعتمد عليها كل لحظات الظهور في `src/timeline.ts` (الكائن `CUES`).

مثال: يظهر «العدد الذري = 6» لحظة نطق «يساوي ستة»، وتنطلق رموز البروتونات لحظة نطق «ستة بروتونات».

النصوص تظهر بتلاشٍ هادئ فقط، ثم تبقى ثابتة دون أي تغيير في كتابتها حتى نهاية المشهد.

## الأوامر

```bash
npm install
npm run studio      # معاينة تفاعلية
npm run render      # تصدير out/atomic-number-lesson.mp4
npm test            # اختبار الملف النهائي: المدة والدقة، ووجود AAC، وسماع الصوت في كل جملة، وثبات النصوص، وحركة الذرة
npm run typecheck
```

يستخدم التصيير WebGL برمجياً (`swangle`)، فيعمل على أي خادم بلا بطاقة رسومات.

## إعادة توليد التعليق الصوتي

النص المشكول موجود في `tools/voice/lines.json`.

**المتطلبات:**

```bash
pip install piper-tts onnx sherpa-onnx soundfile numpy
```

**النماذج:** نموذج الصوت `vits-piper-ar_JO-kareem-medium`، ونموذج التعرف على الكلام `sherpa-onnx-whisper-small`، وكلاهما من إصدارات k2-fsa/sherpa-onnx على GitHub.

**الخطوات:**

```bash
python3 tools/voice/select_takes.py <piper_dir> <whisper_dir> /tmp/voice
cp /tmp/voice/*.wav public/voice/ && cp /tmp/voice/timing.json src/voice-timing.json
tools/voice/normalize.sh
```

يولّد `select_takes.py` ست نسخ من كل جملة، ثم يختار النسخة التي يفهمها Whisper بأقل نسبة خطأ.

يصحّح `synth.py` أخطاء النطق الشائعة في محرك espeak:

- يحذف الهمزة التي يضيفها المحرك قبل «ال» في وسط الجملة (همزة الوصل).
- يمنع تكرار الحرف ثلاث مرات عند اجتماع الشدة مع اللام الشمسية.
- يقف على التاء المربوطة هاءً في مواضع الوقف.

## الملفات

- `src/timeline.ts`: الجدول الزمني ولحظات التزامن.
- `src/direction.ts`: مسار الكاميرا، وتركيب ذرة الكربون-12، وحالة الحركة في كل إطار.
- `src/Atom3D.tsx`: المشهد ثلاثي الأبعاد (النواة، والمدارات، والإلكترونات، وأرقام البروتونات).
- `src/Overlays.tsx`: النصوص العربية والمعادلات ورموز الجسيمات الطائرة.
- `src/Lesson.tsx`: التركيب النهائي، والانتقالات، والصوت والموسيقى.
- `tools/make_music.py`: توليد الموسيقى الهادئة.
