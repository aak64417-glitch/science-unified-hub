صفحة خاصة بالمعلم — لا تُرسل هذا الرابط للإدارة

⚙️ خطوة واحدة قبل التشغيل

لم يُربط رابط التحكم بعد، لذلك تظهر صفحة المدير مغلقة حاليًا. انشر سكربت التحكم مرة واحدة فقط:
  1. افتح script.google.com ← مشروع جديد.
  2. احذف المحتوى والصق الكود أدناه، ثم احفظ.
  3. نشر (Deploy) ← نشر جديد ← تطبيق ويب: تنفيذ باسم أنا، ومن يمكنه الوصول أي شخص.
  4. انسخ رابط تطبيق الويب المنتهي بـ /exec وأرسله ليتم ربطه بالمنصة.
