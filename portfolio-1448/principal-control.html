صفحة خاصة بالمعلم — لا تُرسل هذا الرابط للإدارة

⚙️ إعداد لمرة واحدة على هذا الجهاز

أنشئ «رمز وصول» من GitHub يسمح لهذه اللوحة بتغيير حالة العرض فقط:
  1. اضغط الزر أدناه لفتح صفحة إنشاء الرمز في GitHub (سجّل الدخول بحسابك).
  2. Token name: اكتب مثلًا portfolio-control، وفي Expiration اختر مدة طويلة (مثل 1 year أو Custom).
  3. Repository access ← Only select repositories ← اختر science-unified-hub.
  4. Permissions ← Repository permissions ← Contents ← اختر Read and write.
  5. اضغط Generate token، ثم انسخ الرمز الذي يبدأ بـ github_pat_ والصقه هنا.
🔑 فتح صفحة إنشاء الرمز

يُحفظ الرمز على جهازك فقط ولا يُرفع للمنصة. لا تشاركه مع أحد.
