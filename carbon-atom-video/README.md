# فيديو تعليمي: تركيب ذرة الكربون (Remotion)

- المدة: 10 ثوانٍ — 300 إطار بمعدل 30 إطاراً/ث — الدقة 1920×1080
- النواة: 6 بروتونات + 6 نيوترونات تدور وتنبض في فضاء ثلاثي الأبعاد مُسقَط
- الإلكترونات: 2 في المدار K و4 في المدار L، تدور بحركة متصلة (الإطار الأخير يلتقي بالأول)
- النصوص: العدد الذري ٦ والعدد الكتلي ١٢ بخط Cairo عريض (900)، ثابتة طوال الفيديو

## الأوامر

```bash
npm install
npm run studio      # معاينة تفاعلية
npm test            # اختبار الحركة (فحوص رياضية + مقارنة بكسلات لإطارات مصيَّرة)
npm run typecheck
npm run render      # تصدير out/carbon-atom.mp4 (H.264)
```

يستخدم الإعداد متصفح Chrome Headless المحلي إن وُجد، أو متغير البيئة `REMOTION_BROWSER`،
وإلا ينزّل Remotion متصفحه تلقائياً.

## الملفات

- `src/motion.ts` — حسابات الحركة (دوال نقية قابلة للاختبار)
- `src/CarbonAtom.tsx` — المشهد: الذرة المتحركة والنصوص الثابتة
- `scripts/test-motion.mjs` — اختبارات الحركة
- `out/carbon-atom.mp4` — الفيديو المُصدَّر
